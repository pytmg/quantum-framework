# Quantum Framework Versioning

Current : V0.9.0 - First Quantum Framework Release.

- `-indev` - This will not be seen publicly on the GitHub, it means there are features in development, not considered stable.
- `-beta`/`-nodoc` - Public beta.
- No suffix - Stable release.

The difference between `-beta` and `-nodoc` isn't when they're released, they both *do* mean Public Beta, it just shows quickly whether the documentation for that release is available. If not, there'll either be a complete or partial lack in documentation. 

Expect documentation on stable or `-beta` releases.
